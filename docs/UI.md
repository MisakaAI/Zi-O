# 前端界面与文案

## 视觉与布局

- 采用深石墨背景、分层暗色表面、银灰正文与少量洋红交互色。正文使用系统无衬线字体，时间和编号使用系统等宽字体。
- 顶部统一提供现在、时间线、索引、关于与登录入口；登录后显示工作台和可用键盘操作的账户菜单。
- NOW 以当前时间和近况为主体，日历提供日期上下文，下方展示最近记录和分类、标签索引。
- 时间线保留发生时间、稳定档案编号和永久链接。列表展示纯文本摘要，详情保留后端清理后的完整正文；关联档案出现在普通标签之前，并可直接访问。
- 档案列表采用固定封面比例和按行排列的响应式网格；无封面时使用原创排版占位。
- 记录编辑器在桌面上并排显示正文与属性，在窄屏上先正文、后属性。正文工具栏支持图片上传与 HTML 源代码模式；关联档案和附加分类使用复选框；普通标签直接在正文中输入 `#标签`，保存时自动同步。公开标签使用洋红链接，标签页可选择任意数量标签并按交集筛选。
- 日历年份选择使用原生 `dialog`，限制模态焦点范围，支持 Escape 和关闭按钮，并在关闭后恢复焦点。
- 文本输入、下拉框和编辑区聚焦时使用银灰提示，不显示洋红描边；其他可操作控件仍使用可见的键盘焦点样式。
- 常规交互过渡为 150ms；`prefers-reduced-motion: reduce` 下禁用动画、过渡和平滑滚动。

样式分别位于 `frontend/src/styles/base.css`、`calendar.css` 和 `manage.css`。正文图片使用经用户批准的 `@tiptap/extension-image`，未加入其他依赖。

## 文案约定

- 中文以“记录”指代 Note，以“档案”指代 Item；英文使用 note、entry 和 item，并保持按钮的句首大写风格。
- NOW、LOG、INDEX 与档案编号保留为视觉标识，说明和操作文案随语言切换。
- 空状态说明当前没有什么；错误说明发生了什么及可采取的操作，避免展示 SQL、路径、cursor 等实现细节。
- 记录时间按站点时区显示；编辑器的原生时间控件仍使用设备本地时间，旁边明确提示。
- 站点近况、简介以及用户填写的标题和正文属于内容，不随界面语言自动翻译。
